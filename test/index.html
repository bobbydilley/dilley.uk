WebUSB claim probe

Picks a USB device, shows every interface with its class, and lets you step up from read-only inspection to opening the device and claiming one interface. Each step is a separate button, and nothing is sent to the device: no control transfers, no reads, no writes.

Do this parked, with the car in Park. Claiming an interface detaches whatever driver was using it, so that function stops until you release it or restart the car's media system. Don't claim interfaces on the modem or anything you suspect carries alerts or chimes.

1. Choose and inspect (read-only)

Reads descriptors the browser already collected. The device is not opened.

Nothing selected.

2. Open

Opens a session and selects a configuration if none is active. Still sends no data.

3. Claim one interface

Interfaces in protected classes (audio, HID, video, mass storage and a few others) are blocked by the browser and will fail here. That is expected for a standard audio interface.
